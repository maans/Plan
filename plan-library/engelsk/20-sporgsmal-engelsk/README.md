## Spørgsmålsdækning

### Ord og vendinger
- Hvad betyder det engelske ord eller udtryk ‘lend’? — **låne noget ud**
- Hvad betyder det engelske ord eller udtryk ‘improve’? — **forbedre**
- Hvad betyder det engelske ord eller udtryk ‘avoid’? — **undgå**
- Hvad betyder det engelske ord eller udtryk ‘relieved’? — **lettet**
- Hvad betyder det engelske ord eller udtryk ‘embarrassed’? — **flov**

### Grammatik og udtale
- Hvilken sætning står korrekt i present perfect? — **She has lived here for five years.**
- Hvilken sætning bruger future continuous korrekt? — **At eight, I will be working.**
- Hvilken fortsættelse er korrekt: “If I had known, …”? — **I would have called you.**
- Hvilken verbumsform følger normalt efter modalverbet “must”? — **grundformen uden “to”**
- Hvilken formulering er grammatisk korrekt? — **between you and me**
